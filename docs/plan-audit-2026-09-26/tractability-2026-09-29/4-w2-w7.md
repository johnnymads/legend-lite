## 4. C4 and the cut list: decidable with the data collected?

**C4 (:196-198): not decidable as written.** It names data ("defect data", "W4.0–W4.2's cost") with no threshold and no
mapping from data to option, and the data is not collected: W1.10 pins disagreements "by class" (:465) but nothing records

change amplification. **Proposed:** record per W1.10/W0.6 defect: attributed stage, resolver files/lines touched, whether
the fix added a branch. C4 rule (if D11 = S): **3 (stop)** if ≤ N defects attributed to H on the mapping-heavy set + engine
rows, each fixed in ≤ 1 session with no new special case; **1 (extract passes)** if W4.0–W4.2 ran ≤ 1.5× their re-fitted
size; else **2**. Under R, option 2 is implied (G2). The router in option 2 must be a static per-construct table, never a
try-new-then-old fallback (AGENTS.md invariant 4); its gate is rows (the snapshot cannot apply).

## 6. Top five tractability risks

1. **W2.3a overload** — five variables across ~200 files, ~63 uncounted readers, gate identity depending on a site key the
   item itself changes. *Mitigation:* the §2 decomposition; site-key change first; probes (f) and (g); carve-outs in their own
   push; C2 trigger 15.
2. **The W3 decision cycle plus W3.3 as a big bang** — W3.6 cannot start before D11; W3.3 swaps ~5,000 lines of solver with
   30 catch sites and no size. *Mitigation:* P1, a shadow solver, one selector family per push, W3.0f fuzzing first.
3. **W4.3 on shared mutable state, an unattainable byte gate, and C4 without rules.** *Mitigation:* step 0 (explicit state,
   setter cycles broken); rows+classified-diff gates for steps 6–7; C4 thresholds and per-defect attribution collected from
   W1.10 on.
4. **W3.7 under-specified → D11 ruled on anecdote** — lowering unscoped, graph fetch/M2M without algebra nodes, "escape
   hatch" untested. *Mitigation:* §3's eight points; narrowed cases; a Bazel-deps criterion; a time-box defaulting to S.
5. **W1.10 open-ended before C1, and the mapping-heavy set undefined** — every disagreement fixed or registered before its
   gate, while W1.5/W1.10/W3.7/W4.0 all depend on an undefined set. *Mitigation:* define the set in W1.5 (criteria; the three
   W3.7 cases included); W1.10's gate = "disagreements pinned by class"; the fixes scheduled as W0.6-style pushes with a
   budget counted at C1.
